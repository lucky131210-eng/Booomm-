# Casually Promoting Boba Bash

A small, fun website I made using simple HTML to promote Boba Bash! 

This project is basically my own little way of promoting the event, with a space themed and dark themed background, a Boba Bash logo, cute bubble tea visuals, and some unserious commentary. It's simple, a little chaotic, and made just for fun!

# What is this project?

Casually Promoting Boba Bash is a simple promotional webpage created to spread the word about Boba Bash.

Here's what you'll find:

 A Boba Bash promotional section.
 A space-themed background.
 Cute bubble tea imagery.
 Funny text and a casual, humorous vibe.
 A link inviting visitors to learn more about boba.

It's not a complicated web app — just a small creative project made with basic web development skills.

# How to Try It

Want to check it out yourself? Here's how:
Clone or download this repository.
Open the project folder.
Find index.html.
Double-click the file to open it in your web browser.

I wanted to make something fun to promote Boba Bash, and instead of making a boring promotional page, I decided to give it my own personality.
